### 2. Bugs found and fixed this run (all pushed to main, all built, all retested)

1. **waypaper 2.8-7 -> 2.8-8** (commit 26e48b6) - missing `procps-ng` + `psmisc`.
   waypaper shells out to pgrep/pkill/killall to detect wallpaper backends.
   BEFORE: `Exception: [Errno 2] No such file or directory: 'pgrep'`. AFTER: gone.
2. **fluxer -4 -> -5** (commit 952da0a) - leaked its bundled Electron runtime as
   system Provides (libvulkan.so.1, libEGL.so, libGLESv2.so, libffmpeg.so,
   libvk_swiftshader.so). `dnf install mpvpaper` therefore pulled in **406 MiB of
   fluxer** instead of the 577 KiB vulkan-loader - and mpvpaper still would not
   start. Fixed with `__provides_exclude_from` + dropping the now self-only
   libffmpeg.so Require.
3. **zen-browser -1 -> -2** (commit d19e12f) - same class: 170+ leaked Provides
   from /opt/zen including libnss3.so with every NSS_3.x symbol version,
   libxul.so, libssl3.so, libsoftokn3.so, libfreeblpriv3.so. Fixed the same way
   plus `__requires_exclude` for 7 internal-only sonames.
4. **mpvpaper 1.9-1 -> 1.9-2** (commit 1b332b9) - missing `procps-ng`.
   src/main.c:317 and :1368 call `pidof` via system().
   BEFORE: `sh: line 1: pidof: command not found` (x5). AFTER: gone.
5. **hyprland-contrib -1 -> -2** (commit a8298f8) - audited every contrib script
   against its subpackage Requires. grimblast +procps-ng +hyprctl;
   hyprprop +hyprctl; scratchpad +hyprctl +procps-ng +psmisc;
   **try_swap_workspace had NO Requires at all** -> +jq +hyprctl +procps-ng;
   hdrop +hyprctl. BEFORE: `grimblast: line 27: pidof: command not found`.
6. **logseq 2.0.1-1 -> 2.0.1-2** (commit 6383354) - missing `libaio`. The bundled
   @zvec DiskANN vector-search plugin (dlopen'd) links libaio.so.1; the spec sets
   `AutoReqProv: no` so nothing generated it. BEFORE: `libaio.so.1 => not found`.
   AFTER: whole logseq tree reports 0 unresolved libraries.
