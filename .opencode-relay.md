## Key learnings
1. **COPR repo snapshot issue**: All builds triggered by a single push share the
   same repo snapshot. Packages cannot see other packages built in the same push.
   Must rebuild in waves, waiting for repo recomputation between waves.
2. **hyprutils soname change**: hyprutils 0.14.0 changed from libhyprutils.so.6
   to .so.13. All packages built before hyprutils 0.14.0 need rebuilding.
3. **hyprlang also needs rebuilding**: hyprlang itself links against hyprutils,
   so it also needs to be rebuilt to use the new soname.
4. **hyprland has many implicit deps**: glslang-devel (not glslang), git for
   FetchContent, and all the hypr* libraries.
